# CasePilot — India's AI Legal Case Worker

> Not a legal chatbot. A legal case worker that fights alongside you.

Built for the Google Cloud Rapid Agent Hackathon — MongoDB Track.

## Stack
- Google ADK — multi-agent runtime
- Gemini 2.0 Flash — LLM
- MongoDB Atlas — operational + vector search
- Cloud Run — deployment

## Setup
1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your keys
3. `pip install -r requirements.txt`
4. `python main.py`

## Disclaimer
CasePilot provides legal information only, not legal advice.
